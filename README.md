## 编写规范

1. 简体中文，面向没有开发经验的服主，能照着做
2. **示例必须与插件实际释出的默认配置一致**，可直接复制使用；功能行为变了必须同步改 wiki
3. 每页开头一句话说明"这页解决什么问题"；配置字段用表格列出：字段/类型/默认值/说明
4. 指令、权限、占位符、AX 协议这类"清单页"随每个阶段**持续追加**，不等收尾
5. 新增页面时同步更新本目录表
6. `wiki/` 支持子目录；新增 Markdown 会自动进入公开站点的"其他文档（自动收录）"，无需手动改侧边栏
7. 需要固定分组/顺序时编辑 `.github/wiki-site/config.mts`；不希望自动显示的页面可加 frontmatter：`autoSidebar: false`
